# Pallavi Frontend

React frontend and React administration dashboard for Pallabi Savings & Credit Cooperative.

## Local setup

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Copy `.env.example` to `.env` and set the backend API URL.
4. Run `npm run dev` for the public website.
5. Run `npm run build` to build the public site and dashboard.

The production build is written to `dist/`, with the dashboard under `dist/admin/`.
